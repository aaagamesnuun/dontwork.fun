# WORKの入力上限

通常モードのWORKは、直近1,000msに受け付けた入力が最大15回になります。LABの「WORKの上限（回/秒）」で1〜60の整数に変更できます。値はセーブに保存され、過去のセーブに設定がない場合は15で補完します。資産・WORK累計・確定済みクリア記録は変更しません。標準以外の値を使ったランは既存の比較用ルールに従ってランキング対象外となり、15に戻しても履歴は消えません。

`src/workInput.ts`は画面内で共有する入力受付です。`performance.now()`で直近1秒を数えます。タブやLABの開閉、AUTOの停止・再開、上限変更で受付履歴をリセットしません。超過入力を後で実行するキューや、放置した時間による受付枠の積み増しはありません。WORKを使うLABの手遊びも同じ受付を通します。

入力受付に成功したときだけ既存の`work`を実行し、WORK音と紙幣演出を出します。通常モードでは資金不足・AUTO停止・スピン演出中でもWORKできます。後者では既存presentation reducerがWORK収入を即時表示し、未公開スピン結果を隠したまま後で合流します。ゲームエンジンの計算用`work`関数自体にはUI入力時計を持たせません。

30分モードの入力速度と砂時計による停止ルールは今回変更しません。通常モード専用のLAB入力欄は30分モードでは無効です。別の操作経路が持つ独自制限には影響しません。統計のスナップショットには`workClicksPerSecond`を保存します。

## プレイ確認

- 通常モードのWORKを高速連打しても、直近1秒の収入が$15までで止まり、待った後に超過分が加算されない。
- LABで5回/秒に変更すると上限が変わり、再起動しても5が残る。標準は15。
- スピン中のWORKやギャンブル・アップグレード操作が引き続き使える。

自動テストはローリング期間の境界、長時間待機、LABの即時変更、未公開スピンとの合流、30分停止、保存補完と検証、JP/ENのLAB項目を確認します。実機のタッチ・音・画面の確認は別途行います。
