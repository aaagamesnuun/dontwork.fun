# LAB ガイド

アプリ v3.0.0 の実装に基づく開発・比較用ガイドです。照合したコミットは[README](../README.md#開発者向けの読み方)に記載しています。LABは同じゲームの設定画面で、開くだけでは別のセーブやテスト環境に切り替わりません。変更の多くは現在のランに即時反映され、自動保存されます。

## 開き方と通常プレイとの違い

ゲームのメニューから **「LAB(開発者用)」** を開きます。入口とモーダルは [App.tsx](../src/App.tsx)、設定全体は [Panels.tsx](../src/Panels.tsx) の `Lab` にあります。

通常プレイは「基本7種」、1画面の構成、WORKの連打で+$1、スピン容量制限なし、標準の抽選・価格で始まります。LABでは別のギャンブルセット、ルール、価格、演出を比較し、資産や出目を操作できます。以下の既定値は [engine.ts](../src/game/engine.ts) の `defaultSettings` と [soundPresets.ts](../src/soundPresets.ts) に基づきます。保存済み設定がある場合は、その値が表示されます。

試す前の進行を残すには、一般の設定画面から **「セーブを書き出す」** を使えます。ただし、書き出したセーブを後から読み込んだランはランキング対象外になります。演出の比較だけなら資産追加やルール変更は不要です。

## ランキングへの影響

LABを開くこと自体はランキング適格性に影響しません。判定の中心は [engine.ts](../src/game/engine.ts) の `configure`、`customRules`、`freshRun`、`finish`、`advanceTrial` です。

| 操作・設定 | 影響 |
| --- | --- |
| 表示・音・演出・名前表記・案内の変更、演出プレビュー | それだけではランキング対象外になりません。長いスピン演出は次のスピンまでの待ち時間に影響する場合があります。 |
| コインフリップの入口を有効化 | 既存の公平なコインルールは変わらず、この設定自体では対象外になりません。 |
| バックグラウンド進行・通知の変更 | 進行方法が変わりますが、この設定自体は対象外の印を付けません。 |
| 30分モードの早期解放 | ブラウザに解放状態を保存するだけで、現在のランを対象外にしません。 |
| ジャックポット条件、手遊び、確率強化、WORK方式、WORKコスメ、スピン補助、容量、最初の賭け金、初回Jackpot補助、抽選速度・間隔・回数、価格、強化方式の変更 | 現在値と異なる値を適用すると比較用ラン（`debug: true`）になります。 |
| 資産追加、Compute回復、全解放、カット量の試験、出目指定 | 比較用ランになります。 |
| 資産・強化を引き継ぐギャンブルセット切替 | 比較用ランになります。 |
| 「全ギャンブル実験室」、時間ショップ、時間ガチャで新規開始 | 最初から比較用ランです。 |

**一度比較用になったランは、設定を標準に戻しても対象に戻りません。** 標準条件で新しく遊ぶにはルール設定を既定値に戻し、「基本7種」で最初から開始します。LABのリセットボタンは設定の一部だけを戻すため、後述の対象範囲も確認してください。新規ランは設定を引き継ぎ、`customRules` が既定値との違いを再判定します。

すでに確定した通常クリア記録（`completion`）や30分結果（`trial.result`）は別に保持されます。確定後にLAB設定を変えても、保存済み結果の適格性を遡って書き換える処理ではありません。

通常のクリア記録は、対象ランであることに加え、記録時間・スピン数の上限なども検査されます。30分の標準記録は `fixed`、延長なし、時間購入なし、補助未使用が条件です。LAB記録の名前は端末に保存され、通常の公開ランキングには送信されません。送信処理は [rankingOutbox.ts](../src/rankingOutbox.ts)、[trialScores.ts](../src/trialScores.ts)、サーバー側の受付は [rankings.js](../server/rankings.js)、[bankrollRankings.js](../server/bankrollRankings.js) を参照してください。

この公開リポジトリをローカルや通常のforkで起動した場合、オンラインサービスは既定で無効です。「ランキング対象」はゲーム内の適格性を指し、公式ランキングに送信できることを意味しません。接続条件は [serviceConfig.ts](../src/serviceConfig.ts) にあります。

## 別のバージョン・30分チャレンジ

LAB上部の **「別のバージョン」** を開くと、本番 `dontwork.fun` と v2.3、v2.2、v2.1、v2.0、v1.11.0、v1.10.0、v1.9.0 のリンクが出ます。別サイトへの移動であり、現在のランの版をその場で変更する機能ではありません。リンク先一覧は [ReleaseNotice.tsx](../src/ReleaseNotice.tsx) の `VersionLinks` が管理しています。この一覧はリンク先の稼働を保証するものではありません。

通常は通常モードのクリアで30分チャレンジが解放されます。以前に30分モードを使ったブラウザもアクセスを維持します。未解放でもLABの **「30分チャレンジモードを解放」** で先に試せます。一度解放するとメニューにモード選択が現れます。[trialUnlock.ts](../src/trialUnlock.ts)

| 選択肢 | 内容・操作 | ランキング |
| --- | --- | --- |
| 30分モードへ／通常モードに戻る | それぞれの保存枠に切替。通常モードの進行を別に残します。 | 保存済みランの状態を維持 |
| 新しく30分に挑戦 | 確認後、前回の30分モードを$0から置き換えます。ルール設定を標準化し、初回4スピン補助と2つ目のギャンブル補助、初回Jackpot補助をOFFにします。 | 標準ルールで新規開始 |
| LAB・時間を買える30分 | 支払いで+60秒。 | 対象外 |
| LAB・時間を当てる30分 | 同じ価格で抽選し、50%で+120秒、ハズレは延長なし。 | 対象外 |

時間購入価格は支払いに使う現金の10%（最低$100、整数に切り上げ）です。スコアは **現金＋強化に使った総額**。砂時計ボタンで開始・一時停止します。動作中は資金不足でも時計が進み、WORKができます。一時停止すると時計・WORK・FLIP・スピンが停止します。画面を離れても自動で一時停止し、戻ったら砂時計で再開します。30分モードはバックグラウンドでは進まず、通常モードのAUTO廃止設定も適用しません。ギャンブル変更と強化購入は一時停止中も可能です。

実装は [TimeTrial.tsx](../src/TimeTrial.tsx)、[trialSaves.ts](../src/trialSaves.ts)、[engine.ts](../src/game/engine.ts) の `freshTrial`、`trialTimePrice`、`buyTrialTime` にあります。ギャンブルセットの引継ぎ切替は30分ランでは適用されません。セットを比較するときは通常モードに戻して操作します。

## 名前・金額表示・スピン補助

ジャックポットは通常・30分とも、次回の賭け金を払えなくなると終了します。連鎖の残り回数と一時的なカットが解除され、補充後は通常スピンから再開します。旧カードのカット記憶は既存の比率に従います。

スピン補助のセクションはLABの一番下にあります。BASELINEのON/OFF・各回のチェック・2つ目のギャンブルのON/OFFをまとめています。名前・金額表示は上部に残ります。

| 設定 | 既定値 | 使い方・範囲 |
| --- | --- | --- |
| ギャンブル名 | 英語 | 「日本語・金融用語風」にすると、BASELINE→ベースライン、SLOW CLIMB→スロー・クライムなど、辞書の日本語名に切り替わります。メニューのJP/ENとは独立した表示設定です。 |
| 金額の表示 | 省略 | `$1K / $1M`と`$1,000 / $1,000,000`を切り替えます。表示のみで、ランキングには影響しません。 |
| スピン補助機能 | ON | BASELINEの最初の4スピン補助を有効にします。30分モードでは無効です。 |
| 2つ目のギャンブルのスピン補助 | ON | 入替対象の初回だけ当たりにします。BASELINEの補助とは独立。OFFへの変更で比較用ランになります。30分モードでは無効です。 |
| 1〜4回目のチェック | `WLWW` | 各回のチェックあり=当たり、なし=ハズレ。標準は1・3・4回目がONです。 |

名前設定はランの `Settings` とは別にブラウザへ保存されます。辞書にない名前は英語のままです。[betNamePreferences.ts](../src/betNamePreferences.ts)、[bet-names-ja.json](../src/locales/bet-names-ja.json)、[catalog.ts](../src/game/catalog.ts)

4スピン補助が制御するのは **BASELINEの当たり外れ** で、編成全体の純利益を保証するものではありません。対象のBASELINEは `edge-50` と長時間版の `long-edge-50`。補助はランの総スピン数で位置が決まり、途中で並びを変えても1回目に戻りません。5回目から通常抽選です。資金不足で回せなかった操作はスピン数を消費せず、再読込しても途中の位置が残ります。出目指定の抽選は補助より優先されます。30分モードでは補助を使わず、スイッチと4欄は無効です。旧5文字の標準 `WWLWW` は `WLWW` へ、LABの独自順番は先頭4文字へ移行します。ON/OFF、消費回数、進行と記録、既存のランキング対象外フラグは保持します。[spinAssist.test.ts](../src/spinAssist.test.ts)

「基本7種」「ビリオンへの道」「長時間調整版」のクリックWORKでは、2番目のギャンブル解放後に入替を案内します。入替案内と対象の初回当たり補助は標準で有効です。補助は4スピンの並びより優先し、LABでOFFにできます。Jackpot中でも現在残っている当たり範囲を使い、可能なら90以下を選びます。資金不足では消費しませんが、出目指定または補助OFFで初回を回した場合は、後からONにしてもやり直しません。進行は保存され、再装備や再読込でも初回補助を繰り返せません。

金額表示の選択はランとは別のブラウザ設定です。全桁表示はK/M/Bの省略を外す機能で、数値精度や小数の丸め方を変えるものではありません。金額表記にかかわらず、資産欄は見出しなしの1段表示です。標準は「総資産の数値・クリア目標」を左に、最新の増減を右端に表示します。収まらない長い金額は横にスクロールできます。

補助をOFFにする、または標準の `WLWW` を変更すると通常ランはランキング対象外になります。「初回Jackpot」の補助とは別の設定です。

## バックグラウンド進行と通知（通常モード）

通常モードの背景進行は既定ONです。効果音ON・音量ありで、通知が未許可・拒否済み・非対応でも進行します。Jackpot通知と大きな変動の通知は既定OFF。ヘッダーのベルは通知だけの設定を開き、背景進行のON/OFF・音量はLABの **「音を聞きながら、画面を離れる」** から変更できます。30分モードは説明のみで、通知を許可していても背景進行しません。

1. 音をONにしてAUTOを動かし、他のアプリや画面へ移動すると進行を続けます。
2. Jackpot発生時には通知設定と関係なく一時停止し、到達音を鳴らします。時計は止めたまま到達音を完走させ、戻ったときに再開します。
3. 通知を受けたい場合だけ、ベルから **「ジャックポット通知をONにする」** を押してブラウザに許可します。ベルを開くだけでは許可要求を出しません。通知OFF・拒否で背景進行や効果音の設定は変わりません。
4. 停止するには **「バックグラウンド進行をOFFにする」** を押します。この操作は音や通知の設定まで一括でOFFにはしません。

背景進行には効果音ON、音量が0より大きいこと、Web Locks対応が必要です。音をOFFにすると停止します。通知APIへの対応・通知許可は、通知を受け取るためだけに必要です。iPhone・iPadはホーム画面に追加したアプリから開きます。

LAB限定の **「大きな資産変動も通知」** をONにすると無音で通知します。Jackpot以外の通知は最大1分に1回です。端末がアプリを休止した場合は復帰時に進行を反映するため、休止中の即時通知や音の継続は保証されません。離席1回につき最大1時間・12,000スピンです。

実装は [BackgroundSettings.tsx](../src/BackgroundSettings.tsx)、[backgroundPlay.ts](../src/backgroundPlay.ts)、[jackpotNotifications.ts](../src/jackpotNotifications.ts)。revision 3より前のセーブは通常モードの背景設定をONにし、古い時計チェックポイントを解除します。保存済みのJackpot停止は保持し、後からLABでOFFにした設定も再読込で保持します。30分では常にOFFにします。

## AUTOボタンの廃止（LAB・通常モード限定）

**「AUTOボタンをなくす」** は既定OFFです。ONにするとAUTOボタンを隠し、ギャンブルをセットして賭け金が貯まり次第、自動で回し始めます。比較用ランになります。資金不足・空の編成では回らず、補充・再設定後に再開します。オンボーディング、バックグラウンドのJackpot停止、保存失敗、演出プレビューの停止は維持します。プレビュー後はLABを閉じて再開します。30分モードでは無効で、常に砂時計による開始・一時停止を使います。実装は [automaticPlay.ts](../src/automaticPlay.ts) とAppの周期処理です。

11種類のサウンドパックは **Terminal、Arcade・旧版、Soft・旧版、Crystal、Arcade・v1.3、Wood、Impact、CASH RAIN・8bit、Arcade・Pinball、Arcade・Synth、Arcade・Punch** です。[SoundPackPicker.tsx](../src/SoundPackPicker.tsx)

黄色い線はチャージ中に止まり、スピンが回る瞬間から動きます。長い演出ではJackpot中も決着を待って次のスピンに進む場合があります。一般設定やOSの「動きを抑える」設定も反映されます。時間計算は [spinTiming.ts](../src/spinTiming.ts)、紙幣は [banknotes.ts](../src/banknotes.ts)、描画は [ResultVisuals.ts](../src/ResultVisuals.ts) を参照してください。

### 賭けずに試すボタン

- **賭け金不足の警告音を試す**：警告音を再生。
- **8スピンを試す**：固定のプレビュー出目で当たり・ハズレのリズムを再生。同じボタンで停止。
- **お金の演出を試す**：当たり額を$1／$20／$250／$10K／$1M／$1Bから選択。初期選択は$20で、札の演出を比較。
- **スピン開始／ハズレ／小当たり／大当たり／Jackpot／連鎖**：各演出を個別に再生。
- **5種類を順番に試す**：ハズレから連鎖までを順に再生。同じボタンで停止。
- **音をONにする**：効果音がOFFの場合に表示。

8スピン・お金・個別演出・5種類連続のプレビューはAUTOを停止し、プレビューのための抽選や賭け金消費は行いません。開始前に受け付け済みのスピン結果は通常の確定処理で反映されます。30分モードでは時計も一時停止します。プレビュー終了後の再開は手動です。ただし通常モードのAUTO廃止実験では、LABを閉じると自動再開します。

### BGM（一般設定とも共通）

現行のBGMは **Pulse・弾むシンセ、Night・静かな夜、Arcade・ゲームセンターの3種類** です。既定は通常時OFF、Jackpot中は「通常時と同じ」、選択曲Pulse、音量18%。効果音のON/OFFとは別です。[MusicSettings.tsx](../src/MusicSettings.tsx)

Jackpot中の音楽は「通常時と同じ」「流す（通常時OFFでも）」「流さない」から選べます。通常時OFF＋Jackpot中「流す」で当選時だけBGMを鳴らせます。**通常時BGMをOFFにする操作はJackpot設定も「通常時と同じ」に戻します。** 曲を選ぶ操作は通常時BGMをONにし、「相場で音楽を変える」をOFFにします。音量は0〜100%、5%刻みで調整できます。

### 強化価格の実験室

[PriceLab.tsx](../src/PriceLab.tsx) にあります。全体の価格設定は選択すると即時反映。個別数値は入力してプレビューを見たあと **「この価格で試す」** で適用します。いずれもルール設定です。

| ギャンブル数の価格方式 | 段階式（`steep`） | 一定倍率（`exponential`）、PE旧価格・ギャンブルのみ（`legacy`）。 |

| スピン周期の上昇倍率 | 1.2 | 1.01〜2。`v20`の標準は1.25。 |

「ガチャだけ」の強化方式では個別価格調整とその適用・リセットは無効で、全体の価格設定は選択できます。**「価格を標準に戻す」** は価格プロファイル・価格方式・上記4数値を既定値に戻しますが、ランの対象外状態は解除しません。

| 通常抽選の速さ | 1倍速 | 0.5／1／2／10倍速。内部の待ち時間倍率は2／1／0.5／0.1。 |

強化ガチャは初回$25。実装の価格倍率は現在／前回プロファイルで **1.17倍**、`v20`で **1.18倍** に `nice()` の切上げ丸めを適用します。LAB画面の説明には一律「約1.18倍」という文言が残っていますが、計算値は [engine.ts](../src/game/engine.ts) の `upgradeDrawPrice` が基準です。

有効な補助の優先順は、入替対象の初回当たり（標準ON）→BASELINEの5スピン→初回Jackpotです。出目指定はこれらより優先します。自然にJackpotが出た後は初回Jackpot補助を使いません。

初回当たり補助の標準ONへの変更時、旧通常セーブは一度だけ新しい標準へ移行します。LABランの既存の選択と、更新後にOFFにした設定は保持します。初回スピンの消費状態・過去のクリア記録・ランキング対象外の印はリセットしません。

LABには「Jackpot中はチャート画面に固定」という旧説明が残っていますが、現行動作は当選時にスピン画面へ自動移動するもので、Jackpot中も画面切替・強化・解放済みのFLIPを利用できます。資金やモードの停止状態など、通常の操作条件は必要です。ギャンブルを変更する場合は、Jackpotと出目カットを終了する確認が出ます。[App.tsx](../src/App.tsx)、[spinTiming.ts](../src/spinTiming.ts)

**「抽選設定を標準に戻す」** の対象は、容量、最初の賭け金、初回Jackpot補助ON/OFF・回数、通常速度、Jackpot間隔・基礎回数・条件、強化価格方式・全体プロファイル・4つの個別価格値、強化方式です。最初の5スピン補助、2つ目のギャンブルの補助、手遊び、WORK方式・コスメ、確率強化、表示・音などを一括で戻すボタンではありません。

## 進行・演出の試験（実際のランを変更）

この区画は演出実験室の無消費プレビューとは異なり、現在の資産や進行を変更します。すべて比較用ランになります。[Panels.tsx](../src/Panels.tsx)

| 操作 | 実際の処理 |
| --- | --- |
| +$100／+$10K／+$1M／+$100M | 現金に加算し、最高資産も更新。 |
| Compute全回復 | 現在の容量上限まで回復。容量制限OFFでも比較用の印を付けます。 |
| 全ギャンブル解放 | 最高資産を最低$1Bにする。旧特殊市場では特殊ギャンブルの所有一覧も解放。現在セットにないギャンブルを追加する操作ではありません。 |
| 出目カット +33で連鎖試験 | カット量を**33に設定**し、現金・最高資産を最低$1Kにします。ボタン名の「+33」は現在値への33加算ではありません。 |

## 一般設定・現役の旧機能・廃止機能

- **一般設定にもあるもの**：効果音、サウンドパック、BGM、振動、動きを抑える、演出スタイル、セーブの書出し／読込み。LABの音設定と同じ設定値を使います。一般設定のスピン表示は「Payoff Sweep」と「大きな数字」を選べます。
- **現役の比較用旧機能**：旧タブ式、PE風の音やSweep、旧サウンドパック、旧価格プロファイル、PE旧ギャンブル価格、旧特殊市場。画面に旧版名があっても現在選択できます。
- **廃止済みの出目サイコロ**：`rollDisplay` は現在 `number` のみです。`dice` のUIはなく、古いセーブの値も読込時に `number` へ移行します。一般設定の「大きな数字」（`reelStyle: number`）やPayoff Sweepとは別の設定でした。
- **現行のBGM候補にない旧曲名**：`bit-quest`、`pixelland`、`cipher`、`envision` は読込時にPulseへ移行し、通常時BGMをOFF、Jackpot音楽を「通常時と同じ」に戻します。現在の選択肢は前述の3種類です。
- **コードに残るだけの項目**：バカラの型・処理・コンポーネントはありますが、現行LABに有効化スイッチはありません。`baccarat` は既定OFFで、ONやプレイ履歴は比較用判定に含まれます。現在のLABの選択機能として扱わないでください。

廃止・移行の根拠は [engine.ts](../src/game/engine.ts) の `readSave` と [release30.test.tsx](../src/release30.test.tsx)。LABへ項目を追加・変更するときは、画面だけでなく `Settings`、既定値、保存移行・検証、`configure`／`customRules` のランキング判定も合わせて確認してください。


## コインフリップ（LAB限定）

「画面・遊び方の比較」の **「コインフリップを試す」** は既定OFFです。ONにすると、公開済みの最高資産が$10Kを超えた後だけ切り替えボタンに追加されます。解放案内は一度だけ表示し、資産が下がってもLAB設定がONなら利用できます。パネル内のスイッチをONにして初めてWORKがFLIPになります。

OFFに戻すと通常のWORKへ戻り、コインの入口・新たな解放案内・通常ヘルプの説明を隠します。過去のコインの賭け金・収支は記録から消さず、プレイ歴のあるクリアカードには残します。次のスピンにまだ合流していないコイン収支も、そのまま次の決着でチャートへ反映します。設定のない旧セーブはOFF、30分チャレンジの新規開始もOFFです。この移動は機能の公開範囲の変更で、1/2で2倍の配当やランキングの扱いは変えません。
